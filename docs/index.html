rossh

An SSH server and client for ReactOS and older Windows.

One static executable. Nothing to install on the target beyond picking a key, and any stock SSH client connects to it with no special options - modern key exchange and ciphers, public-key authentication, exec, scp/SFTP and an interactive shell. Verified on ReactOS 0.4.16 and Windows 7 SP1.

Running it

Run the installer on the ReactOS or Windows machine. It asks for the public key to authorise and the port to listen on, installs to C:\Program Files\rossh, and registers an auto-start service. Then, from anywhere else:

$ ssh  user@reactos-box "dir C:\"             run one command
$ scp  notes.txt user@reactos-box:/notes.txt  copy a file (to C:\notes.txt)
$ ssh  user@reactos-box                       open a shell

The same binary is also the client, so the ReactOS box can reach out as well: copy it to ssh.exe, or pass --client. Keys are ed25519 in PKCS#8 DER, and rossh --genkey writes a pair.

Worth knowing

The server handles one session at a time, authenticates by key only without checking the user name, and its SFTP root is a starting directory rather than a jail. The interactive shell on ReactOS and Windows is line-oriented - there is no ConPTY there, so full-screen programs are out of scope. The README lists all of it.
